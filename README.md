# מערכת ניהול יחידת 3901 - הר אדר

אפליקציית PWA (Progressive Web App) לניהול יחידת כבאות והצלה - לוח משמרות,
ניהול רכב וציוד, אירועים, אימונים, נהלים ובקשות מיוחדות.

הנתונים נשמרים ב-Firebase (Firestore) - כל המתנדבים שנכנסים לאותו קישור
רואים ומעדכנים את אותם נתונים בזמן אמת.

## הרצה מקומית (לבדיקה לפני פרסום)

צריך [Node.js](https://nodejs.org) מותקן (גרסה 18 ומעלה).

```bash
npm install
npm run dev
```

יפתח שרת מקומי (בדרך כלל בכתובת `http://localhost:5173`). פותחים בדפדפן
ובודקים שהכל עובד - לוח המשמרות, שמירת נתונים וכו'.

## פרסום לאינטרנט (Vercel + GitHub)

### שלב 1: להעלות ל-GitHub

1. נכנסים ל-[github.com](https://github.com) ויוצרים חשבון (אם אין)
2. יוצרים repository חדש (New repository), למשל בשם `har-adar-3901`
3. מעלים את כל התיקייה הזו ל-repository (או דרך האתר של GitHub - "uploading
   an existing file" - או דרך `git` בטרמינל אם נוח)

### שלב 2: לחבר ל-Vercel

1. נכנסים ל-[vercel.com](https://vercel.com) ונרשמים עם חשבון GitHub
2. "Add New Project" ובוחרים את ה-repository שיצרתם
3. Vercel מזהה אוטומטית שזה פרויקט Vite - לא צריך לשנות שום הגדרה
4. לוחצים "Deploy"

תוך דקה תקבלו כתובת קבועה כמו `har-adar-3901.vercel.app` - זו הכתובת
ששולחים לכל היחידה.

**מכאן והלאה:** כל פעם שהקוד ב-GitHub מתעדכן (למשל בעריכה עתידית איתי),
Vercel בונה ומפרסם גרסה חדשה אוטומטית תוך פחות מדקה.

## התקנה על מסך הבית בטלפון (PWA)

אחרי שהאתר עולה לאוויר:
- **אנדרואיד (כרום):** נכנסים לאתר → תפריט שלוש נקודות → "התקן אפליקציה" /
  "הוסף למסך הבית"
- **אייפון (ספארי):** נכנסים לאתר → כפתור השיתוף (הריבוע עם החץ) → "הוסף
  למסך הבית"

יופיע אייקון אמיתי, והאפליקציה תיפתח במסך מלא בלי סרגל כתובת של הדפדפן.

## חשוב - אבטחת הנתונים (Firestore Rules)

כרגע ה-Firestore רץ במצב "test mode", שפתוח לגמרי וכנראה **יפוג תוך 30 יום**
מיצירת הפרויקט. כדי שהאפליקציה תמשיך לעבוד:

1. ב-Firebase Console → Firestore Database → הלשונית **Rules**
2. מעתיקים לשם את התוכן של הקובץ `firestore.rules` שנמצא בתיקייה הזו
3. Publish

הכללים האלה משאירים את הגישה פתוחה לכל מי שיש לו את כתובת האתר (אין מערכת
התחברות באפליקציה כרגע - כמו קבוצת וואטסאפ, מי שיש לו את הקישור, נכנס). זה
מספיק לצוות מתנדבים קטן וסגור, אבל **לא מתאים** אם רוצים שהאתר יהיה פתוח
לגוגל/לכל האינטרנט.

## מבנה הפרויקט

- `src/App.jsx` - כל 10 המסכים של האפליקציה (לוח משמרות, רכב, ציוד וכו')
- `src/storage.js` - השכבה שמחברת את האפליקציה ל-Firebase (את זה לא צריך
  לגעת בו)
- `src/main.jsx` - נקודת הכניסה
- `public/icons/` - אייקוני האפליקציה (מהלוגו של היחידה)
- `firestore.rules` - כללי האבטחה המומלצים ל-Firestore
